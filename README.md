# 科目一通关笔记

驾照科目一（道路交通安全法律、法规和相关知识）的复习页面，纯前端，手机电脑都能看。

**在线地址** → https://vagee9157.github.io/kemu1/

## 有什么

| 板块 | 内容 |
|---|---|
| 📖 考点 | 8 章 49 个考点，按考试分值排；每条标「必考 / 常考」，附一句话记忆口诀；可搜索、可勾「已掌握」 |
| 🔢 速记 | 数字题汇总（驾驶证年限、记分、速度、距离、高速低能见度）+ 易混对比表；可「遮住答案」点开自测 |
| ✍️ 刷题 | 384 道题（含 200 道看图题，高频 160 道）：高频必刷 / 模拟考试（随机 50 题，交卷出分）/ 全部顺序 / 按章节；答完即出解析并可跳回对应考点 |
| 📕 错题 | 做错自动收录，按错误次数排，重做答对即移出 |

学习进度、错题只存在本机浏览器（localStorage），换设备或清缓存会丢。

联网打开过一次后可以离线使用；「添加到主屏幕」后像 App 一样全屏打开。

## 内容依据

- 《中华人民共和国道路交通安全法》《道路交通安全法实施条例》
- 《机动车驾驶证申领和使用规定》（公安部令第 162 号，经第 172 号修改，2025-01-01 起施行：大中型客货车年龄上限 63、普通摩托车 70）
- 《道路交通安全违法行为记分管理办法》（公安部令第 163 号，2022-04-01 起施行）

题目按公开题库常见题型整理改写，答案以法规原文为准，最终以官方考试系统为准。

已核对的几处"新规"口径（2026-10）：
- 记分规则仍是 2022 版 163 号令，网传"2026 年 6 月新版记分 / 高速打电话 9 分"不是现行规定；
- 私家车年检按现行便民政策：10 年内第 6、10 年上线，10 年以上每年一次；
- 《道路交通安全法》修订草案 2026-08 一审，尚未生效，未纳入考点。

## 自检

```bash
node tools_validate.js
```

检查题库结构（答案下标、选项重复、图是否存在、题干重复）并按章统计题数 / 高频 / 看图。

## 加题 / 改内容

只改 `assets/data.js`。改完把 `index.html` 和 `sw.js` 里的 `?v=N` 一起加 1，再把 `sw.js` 的 `CACHE` 版本号加 1，回访的人才会拿到新版。

题目格式：

```js
{ ch: 'road', hot: 1, type: 'single', q: '题干', opts: ['A', 'B', 'C', 'D'], a: 2, exp: '解析' }
{ ch: 'road', hot: 1, type: 'judge',  q: '题干', a: true, exp: '解析' }
```
